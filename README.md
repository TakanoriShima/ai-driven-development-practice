# AI Training Support

## 概要

AI Training Support は、AI 研修の企画・準備を支援するためのシンプルな Web アプリケーションです。

このアプリケーションは、Python と Streamlit を使用して構築されています。

現在は、研修情報の入力・確認と、入力した研修情報をもとにした研修概要文の自動生成機能を実装しています。

## 主な機能

- 研修情報の入力
  - 研修タイトル
  - 対象者
  - 研修テーマ
  - 研修時間
  - 備考
- 入力内容の確認
- 必須項目の入力チェック
- 入力した研修情報から研修概要文を自動生成
- 生成した研修概要文を画面に表示

## 使用技術

- Python
- Streamlit

## セットアップ方法

1. **リポジトリをクローンする**

   以下のコマンドを使用してリポジトリをローカル環境にクローンしてください。

   ```bash
   git clone git@github.com:TakanoriShima/ai-driven-development-practice.git
   ```

2. **プロジェクトディレクトリに移動する**

   ```bash
   cd ai-driven-development-practice
   ```

3. **必要なライブラリをインストールする**

   `requirements.txt`を使用して、必要なライブラリをインストールします。

   ```bash
   pip install -r requirements.txt
   ```

## アプリケーションの起動方法

以下のコマンドを実行してアプリケーションを起動します。

```bash
streamlit run app.py
```

ブラウザでアプリケーションが表示されます。

## 使い方

1. 研修タイトル、対象者、研修テーマ、研修時間、備考を入力します。
2. 「入力内容を確認」を押すと、入力した研修情報を確認できます。
3. 「研修概要を生成」を押すと、入力内容をもとに研修概要文を自動生成します。
4. 研修タイトルと研修テーマは必須項目です。
